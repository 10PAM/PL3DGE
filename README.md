# About
PL3DGE is a general multipurpose 3D game engine made to be "lightweight" like its name implies. This means that PL3DGE will handle all 3D graphics rendering, so long as you can handle all the debugging and 3D implementation needs for your project(s). Governed under an open-source license, you can modify, share, and redistribute as needed.

# Features
###Programmed in C++
###Graphics API: Vulkan
###Audio API: OpenAL (Open Audio Library)
